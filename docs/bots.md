# Боты

Все боты работают в одном контейнере `bots` и обращаются к координатору по MCP, каждый со своим токеном доступа. Что боту можно, решает координатор; признаки в настройках бота служат только для удобства (например, не отвечать чужим).

## Приёмщик

Бот владельца без модели. Отвечает только владельцу и только в личном чате, остальные сообщения молча игнорирует.

**Что можно прислать**

| Присланное | Что происходит |
|---|---|
| Текст | Сохраняется в личные заметки, ответ «Сохранено» с кнопкой «🗑 Удалить» |
| Фото, документ, видео, аудио, голосовое | Сохраняется в личные заметки вместе с подписью, если OpenViking поддерживает формат; иначе ответ «Формат не поддерживается». Файлы больше 20 МБ Telegram боту не отдаёт |
| Ссылка на веб-страницу | Страница скачивается и сохраняется в Markdown со ссылкой и датой получения. Если страницу получить нельзя, в ответе будет причина |
| Пересылка | Сохраняется в личные пересылки с отправителем: `from_user_id` при открытом отправителе, `sender_name` при скрытом. Фото из пересылки сохраняется всегда, файлы — по тому же правилу формата |
| Ссылка `t.me/…` или `@username` на канал или группу | Кнопки «собирать полностью», «только сводка», «не подключать» |
| Ссылка на человека или пересылка от открытого отправителя | Кнопка «👤 Подключить переписку» |

Уже подключённые источники повторно не предлагаются. Повторная доставка того же сообщения Telegram не создаёт второй записи.

**Команды**

| Команда | Действие |
|---|---|
| `/status` | Состояние источников и сбора, ошибки сбора; у каждого источника кнопки «Пауза», «Отменить» и «🖼 Картинки: вкл/выкл» |
| `/pause <источник>` | Приостановить сбор источника |
| `/cancel <источник>` | Отменить текущее задание источника; архив и расписание не меняются |
| `/undo` | В ответ на «Сохранено» — удалить эту запись (как кнопка «🗑 Удалить») |
| `/groups` | Группы с общим Собеседником и доступ к ним |
| `/digest_time HH:MM` | Час ежедневной сводки; действует со следующего дня |

Картинки из источника скачиваются, только если владелец включил их кнопкой в `/status`; при подключении настройка всегда выключена, уже собранное не докачивается. У источников «только сводка» кнопки нет.

Удаление мягкое: запись помечается `deleted`, прежние редакции остаются в архиве, из поиска она пропадает после проекции.

Раз в 5 минут Приёмщик забирает оповещения координатора: Собеседника добавили в группу, устарели куки NotebookLM, сбор остановился с ошибкой. Оповещение считается доставленным только после успешной отправки.

## Собеседник

Бот с моделью. Модели доступны только два средства — `knowledge_search` и `knowledge_read`; чат подставляет код, а не модель. На один вопрос — не больше 4 шагов модели. Ответ строится только по найденным материалам со ссылками на источники; если подтверждения нет, бот так и говорит.

Экземпляр описывается в настройках: имя, модель, «только владелец», право на сводки. В развёрнутой системе работает один Собеседник — «общий»; «мой» пока только в коде и тестах ([планы](roadmap.md)).

- **«Мой»** (`owner_only: true`, `digest: true`) — отвечает только владельцу в личном чате, видит всю память, делает сводки. Можно спросить о конкретном человеке: поиск вернёт его личную переписку и пересылки от него.
- **«Общий»** (`owner_only: false`) — отвечает в личных чатах и группах, видит только общую память и только в пределах, разрешённых владельцем для группы.

В группе Собеседник отвечает на упоминание, ответ на своё сообщение и `/ask`. Если ничего не найдено — молчит.

## Группы с общим Собеседником

1. Перед добавлением общего Собеседника в группу выключите для него privacy mode через BotFather: `/setprivacy` → выбрать бота → `Disable`. Иначе бот не увидит обычные сообщения группы и не сможет надёжно обрабатывать упоминания и ответы.
2. Добавьте бота в группу. Приёмщик пришлёт оповещение с кнопками доступа.
3. Выберите, что бот видит в этой группе: ничего, всю общую память или отдельные каналы. Позже доступ меняется командой `/groups`.

Пока доступ не выбран, Собеседник в группе ничего не находит. Личная область «общему» недоступна ни при каких настройках.

## Сводки

Команда `/digest` у Собеседника «мой» и ежедневная сводка по расписанию описаны в [отдельном разделе](digests.md).

## Настройки и секреты

Настройки без секретов — файл JSON, путь к которому задаёт переменная `BOTS_CONFIG_FILE` (в контейнере `/run/config/bots.json`, на сервере `/etc/telegram-memory/config/bots.json`): пути к файлам секретов, адрес координатора, общий `base_url` прокси модели, Приёмщик и список Собеседников. Файл собирает `scripts/config-setup.sh`, владелец отвечает только на два вопроса — адрес прокси и модель; смена модели не требует пересборки образа. Секреты — файлами Docker secrets: токены Telegram каждого бота, токены доступа к координатору, ключ прокси модели. Неполные настройки останавливают запуск с понятной ошибкой. Подготовка секретов — в [развёртывании](deployment.md).
