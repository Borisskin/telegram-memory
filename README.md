# Telegram Memory

Личная память из Telegram: архив каналов, групп, своих заметок, веб-страниц и личных переписок с поиском и ответами по источникам.

Всё сохранённое лежит в обычных Markdown-файлах. Поисковый индекс строится из них и в любой момент пересобирается заново, поэтому архив не зависит от поиска и читается любым Markdown-приложением.

## Что умеет

- **Сохранять без вопросов.** Пишете или пересылаете боту-Приёмщику текст, файл, ссылку на страницу или сообщение — он сразу отвечает «Сохранено». Ошибочное удаляется кнопкой.
- **Подключать источники.** Под ссылкой на канал или группу Приёмщик предлагает кнопки «собирать полностью» и «только сводка», под ссылкой на человека — «Подключить переписку».
- **Отвечать по памяти.** Бот-Собеседник ищет в архиве и отвечает только по найденному, со ссылками. Если подтверждения нет, прямо говорит «не нашёл».
- **Работать в группах.** Общего Собеседника можно добавить в группу. Какие каналы он там видит, решает владелец; личное ему недоступно.
- **Делать сводки.** Каждое утро одна сводка по шумным группам. По запросу — за период до трёх месяцев: до недели сводку пишет своя модель, дольше — NotebookLM.

## Как устроено

Четыре контейнера Docker:

- **координатор** — архив, сбор, поиск и права доступа;
- **bots** — Приёмщик и Собеседники;
- **telegram-mcp** — чтение Telegram и NotebookLM;
- **OpenViking** — поисковый индекс.

Записывать в память может только Приёмщик. Собеседники умеют лишь искать и читать, а что им видно, решает координатор по токену каждого бота.

Подробно — в [архитектуре](docs/architecture.md).

## Быстрый старт

Сервер: Ubuntu 24, 2 ядра и 4 ГБ памяти. Если Docker не установлен, его поставит скрипт обновления.

```bash
git clone https://github.com/Borisskin/telegram-memory && cd telegram-memory
sudo scripts/config-setup.sh                               # адрес прокси модели и модель Собеседника
sudo scripts/secrets-setup.sh --cookies /tmp/cookies.json  # куки NotebookLM, переданные scp
sudo scripts/secrets-setup.sh                              # секреты: внешние спрашивает, остальные вычисляет
sudo scripts/update.sh                                     # собрать, проверить, запустить
```

Дальше каждое обновление — `sudo scripts/update.sh`. Какие секреты нужны, как получить куки, как читать итоги и журналы — в [развёртывании](docs/deployment.md).

## Ограничения

- Сервера с 2 ядрами и 4 ГБ хватает впритык: пределы памяти контейнеров заданы, но реальная вместимость ещё не замерена.
- Резервная копия архива пока не автоматизирована — см. [развёртывание](docs/deployment.md#резервная-копия).
- NotebookLM работает через неофициальный API и может сломаться без предупреждения.
- Telegram-сессия владельца даёт полный доступ к учётной записи: система только читает, но сессию нужно беречь как пароль.
